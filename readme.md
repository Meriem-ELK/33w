# TP2 - Site de voyage

### Deuxième étape du développement d'un thème WP

#### Auteur : Meriem El kouarir

### Description : 
- L’objectif du projet est de créer un site WordPress pour un club de voyage.
Ce site a pour but de proposer aux membres du club des voyages exclusifs vers des destinations uniques à travers le monde.

- Il permet de naviguer facilement entre différentes catégories de destinations (Aventure, Culture, Croisière, etc.), afin que chaque membre puisse trouver un voyage correspondant à ses envies.

- Le site a été déployé sur un serveur distant.
